# 桌面快捷方式自动收纳实现计划

## 目标

在不影响现有下载接管和扩展名清扫的前提下，自动把程序运行期间桌面新增的 `.lnk` 移入最符合快捷方式聚类规则的用户收纳箱。

## 任务 1：持久化栅栏类型并迁移旧配置

涉及文件：`src/config.rs`、`src/main.rs`。

1. 增加可序列化的 `FenceKind`，区分用户收纳箱、文件夹栅栏、下载箱和仅用于反序列化缺省字段的旧配置状态。
2. 增加旧配置迁移函数，按下载箱 ID、旧式无目录箱和 `boxes` 直属目录依次识别类型。
3. 在 `config::load` 返回前完成迁移。
4. 新建文件夹栅栏、用户收纳箱和下载箱时写入明确类型。
5. 下载箱复用已有目录时纠正其类型。
6. 添加配置迁移和新配置默认行为测试。

## 任务 2：实现纯函数统计与目标排序

涉及文件：`src/main.rs`。

1. 增加收纳箱统计值结构，记录栅栏 ID、快捷方式数和普通文件数。
2. 实现顶层目录统计：仅实际文件参与，`.lnk` 大小写不敏感，目录忽略。
3. 实现确定性目标排序：全零时空箱优先；否则比较占比、快捷方式数量和反向 ID。
4. 比例用 `u128` 交叉相乘，避免除零和浮点误差。
5. 为所有排序分支和文件分类添加单元测试。

## 任务 3：接入桌面新增快捷方式处理

涉及文件：`src/main.rs`。

1. 给全局状态增加桌面快捷方式待处理集合，复用已有 `desktop_rx`，同时监听当前用户桌面和公共桌面。
2. 每秒接收并合并 `.lnk` 桌面事件。
3. 用文件长度、修改时间和连续稳定次数判断写入完成。
4. 稳定后只枚举有效的 `Collection` 栅栏，选择目标并调用现有 `move_to_dir`。
5. 无有效用户收纳箱时结束候选并保留桌面文件；移动失败时保留候选重试。
6. 移动成功后刷新目标栅栏并维护桌面图标禁放区。
7. 确保该流程始终启用，且与下载接管开关互不影响。

## 任务 4：文档与验证

涉及文件：`README.md`。

1. 在特性和使用说明中补充快捷方式自动收纳行为与选择规则。
2. 运行 `cargo fmt --check`、`cargo test`、`cargo check`。
3. 检查最终 diff，确认没有夹带现有未跟踪文件或无关改动。
